# 🚀 منظومة بناء رومات Alshka-WISP الرسمية (Firmware Builder)

منظومة متكاملة لإنتاج وتجميع رومات رسمية بصيغة **`.bin`** أو **`.img.gz`** مدمج فيها نظام **Alshka-WISP** بالكامل لراوترات **Xiaomi AX3000T** وسيرفرات **x86_64**.

---

## 🛠️ الطريقة الأولى: البناء السحابي المجاني بنقرة واحدة (GitHub Actions) - [الموصى بها]

لا تحتاج لتثبيت أي برامج أو نظام لينكس على جهازك! تتم عملية البناء على سيرفرات GitHub السحابية فائقة السرعة مجاناً:

1. أنشئ مستودعاً جديداً (New Repository) في حسابك على [GitHub](https://github.com).
2. ارفع مجلد `alshka_firmware_builder` بالكامل إلى المستودع.
3. اذهب إلى تبويب **Actions** في صفحة المستودع.
4. اختر من القائمة: **`Build Alshka-WISP Firmware`**.
5. اضغط على **`Run workflow`** واختر:
   - الجهاز المستهدف: `xiaomi_ax3000t` أو `x86_64` أو `both`.
6. انتظر 3 إلى 4 دقائق فقط، وستجد الروم جاهزاً للتحميل مباشرة في صفحة الـ Artifacts!

---

## 💻 الطريقة الثانية: البناء محلياً على سيرفر أو نظام لينكس (Ubuntu / VPS)

إذا كان لديك سيرفر Ubuntu أو جهاز لينكس، فقط نفّذ:

```bash
chmod +x build_firmware_local.sh
./build_firmware_local.sh xiaomi_ax3000t
```
* لبناء روم سيرفرات الكمبيوتر x86_64:
```bash
./build_firmware_local.sh x86_64
```

ستجد ملفات الروم الناتجة داخل مجلد `output/`.

---

## 📦 محتويات الروم المدمجة:
* نظام OpenWrt 24.10 الرسمي المستقر.
* حزمة **`alshka-wisp`** المدمجة بكامل ميزاتها ومحركاتها.
* تسريع العتاد **MediaTek Hardware Flow Offloading (WED)** لأقصى أداء وسرعة جيجابت كاملة وبينغ منخفض.
* خوارزمية **CAKE Traffic Shaper** لكبح السرعات ومنع الـ Bufferbloat.
* واجهة LuCI الداعمة للغة العربية والوضع الليلي Dark Mode.
* إعدادات افتراضية مسبقة، بحيث حتى لو قمت بعمل **Factory Reset** للراوتر، يقلع الراوتر جاهزاً بنظام Alshka-WISP فوراً!
